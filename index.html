05 — Engineering Stories

Challenges I Solved

01
PCB Design · Auto Water Pump
Preventing Motor Burnout on Dry-Run
The pump would run even when water levels were dangerously low, risking burnout. I implemented a monostable NE555 timing circuit with an adjustable potentiometer — the pump now auto-cuts after a configurable ON-duration, preventing dry-run damage without any microcontroller logic.
02
PCB Layout · KiCad
High-Current Trace Failures at 3–5A
Initial PCB traces were too thin for the pump's 3–5A load, causing heat buildup and potential failure. I recalculated trace widths using IPC-2221 standards, added a GND copper pour for thermal dissipation, and integrated a flyback diode to suppress relay voltage spikes.
03
Full-Stack · Slumini
Real-Time Data Without Page Refresh
Early versions required manual refresh to see new messages and job postings. Switched to Firebase Firestore's onSnapshot listeners — all data now updates instantly across all users simultaneously, with zero polling overhead.
